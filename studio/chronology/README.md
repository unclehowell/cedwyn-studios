# Chronology

The film chronology (cedwyn-movie CHRONOLOGY.json, chronology version 1.0.0, 755 events, 685 KB) is kept in R2, not in git:

- key: `studio/chronology/CHRONOLOGY.json`
- sha256 and size: see `studio/manifest-shared.json`

Scenes cite chronology and catalogue ids (EV-, CH-, PX-, MR-) in `scene.json` → `sources.catalogue_ids`; the public evidence catalogue on the Cedwyn site is the reference for each id. The chronology text quotes outside records verbatim, so it stays out of the public repo text.
